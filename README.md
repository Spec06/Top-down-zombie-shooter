# Top Down (Prototype)

Small pygame-based poker prototype. Run locally with Python and pygame installed.

Quick start (PowerShell):

```powershell
python -m venv .venv; 
.\\.venv\\Scripts\\Activate.ps1; 
pip install -r requirements.txt; 
python Projekt/main.py
```

Requirements:
- Python 3.8+
- pygame

Tests:

```powershell
pip install -r requirements.txt
pytest -q
```
