3) Projekt/main.py
- Zweck: Einstieg, init, Loop, orchestriert Systeme
- Signaturen:
  def main() -> None
  def game_loop() -> None
- Minimal-Workflow:
  - pygame.init()
  - screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT), DOUBLEBUF|OPENGL)
  - render_system.init_opengl(...)
  - player = Player()
  - camera = Camera(player)
  - while running: events = input_system.poll_input(); player.update(dt, events); camera.update(player); render_system.draw_scene(...)
- Beispiel (pseudocode):
  def main():
      pg.init()
      screen = pg.display.set_mode((settings.SCREEN_WIDTH, settings.SCREEN_HEIGHT), DOUBLEBUF|OPENGL)
      render_system.init_opengl(settings.SCREEN_WIDTH, settings.SCREEN_HEIGHT)
      player = Player(0,0)
      camera = Camera(player)
      clock = pg.time.Clock()
      while True:
          dt = clock.tick(settings.FPS) / 1000.0
          input_state = poll_input()
          if input_state['quit']: break
          player.update(dt, input_state)
          camera.update(player)
          render_system.begin_frame()
          render_system.draw_ground()
          render_system.draw_player(player)
          render_system.end_frame()
- Minimal-Test:
  - Starten: python Projekt\main.py
  - Erwartet: Fenster öffnet, kein Exception, Esc schließt
- Commit: "Add main entry and loop"

      events = pg.event.get()
      keys = pg.key.get_pressed()

Tägliche Dev-Loop (empfohlen)
- Implementiere eine Datei → commit
- Starte main.py → verifiziere minimalen Test
- Wenn Fehler: stoppe, debugge lokal (prints, set DEBUG_DRAW_HITBOX True)
- Wenn alles OK → nächste Datei

Konkrete Fehlerquellen / Tips
- Pygame + PyOpenGL: bei OpenGL-Fehlern zuerst mit 2D blits testen (pygame.Surface.blit) bevor Shader/GL-Code
- Vektor-Richtungen: Konvention (Z-Forward oder -Z-Forward) konsistent halten
- Kollisionsradius: kleine Toleranzen (epsilon) verwenden
- Delta time: clock.tick(FPS)/1000.0 → dt in Sekunden
- Beim Multithreading / Asynchronität: keine, alles im Hauptthread
